# mood-counter 🐋

鲸鱼娘的心情计数器 —— 一个用来学习 Git 和 GitHub 的最小项目。

## 这是什么

一个单文件网页。点按钮给鲸鱼娘加分或减分，心情值变化时她的表情和台词也会跟着变。

心情值范围是 -100 到 100，初始值为 100。

## 怎么运行

不需要安装任何东西。双击 `index.html`，用浏览器打开就行。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部代码，HTML + CSS + JS 都在这一个文件里 |
| `README.md` | 就是你正在看的这份说明 |
| `.gitignore` | 告诉 Git 哪些文件不用管 |
